# Рубиновая деревня · Ruby Village

Первая глава «За калитку»: восемь спокойных головоломок для детей 6–7 лет. Без таймера, очков и наказания. Песочница сохраняет переключение 7×5,9×6,11×7.

**Играть:** https://maks.live/ruby-village/

## Запуск

TypeScript + Vite + SVG, без серверной части и runtime-зависимостей. Node22.18+ (CI24).

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Открой адрес Vite с `/ruby-village/`. Игра работает только в альбомной области браузера: при высоте больше ширины появляется экран поворота. Расстановка, диалоги и прогресс сохраняются при возвращении без перезагрузки. Полноэкранный режим необязателен.

## Управление и глава

- Выбрать и поставить: фигура → клетка → поворот при необходимости → «Поставить». Клик фиксирует место; наведение только предлагает его.
- Перетаскивать: Pointer Events для мыши/касания. На телефоне цель выше пальца. Ошибка и pointercancel возвращают фигуру в прежнее положение.
- Большая фигура перемещается целиком и вращается на60°. Точка — опорный гекс. ⊘ и красный пунктир означают недопустимое размещение.
- Нажатие на уложенную фигуру выбирает весь экземпляр. Доступны перенос, поворот, возврат в набор и отмена подтверждённого действия.
- «Проверить» ищет связный путь по шести соседям. Можно оставить лишнюю фигуру в наборе.
- Мост: три клетки, середина на воде, оба конца на суше. Обычные плиты на воду и препятствия не ставятся.

Главное меню предлагает начать/продолжить, выбрать уровень и настройки. Карта последовательно открывает места; пройденные можно повторить. Меню паузы возвращает в игру, на карту, к подтверждённому перезапуску или настройкам. Модальные окна и портретный экран приостанавливают движение Руты. После победы — проход, реплика и результат с переходом к следующему месту/на карту. Глава2 пока не реализована.

## Оформление v6

Восемь цельных альбомных PNG, отдельная регулярная логическая сетка11×7 и общая проекция земли yScale=.65. Фон помещается целиком без растяжения; указатель использует обратную проекцию. Рута сохраняет пропорции, передвигается по точке подошв. Плиты используют утверждённые v5 материалы с математической маской.

По уточнению Максима раскладки и наборы перепроектированы под фоны. Эталоны проверены; первый уровень требует семь одиночных плит, следующие допускают лишнюю. Река и мост есть на ручье и у мельницы; в лесном фоне реки нет. Контуры препятствий заданы вручную, не по цвету пикселей. Изображения дерева и клумбы не дублируются, маршрут проходит вне закрытых областей. Уникальность решений не заявляется.

Интерфейс — живые DOM/CSS/SVG элементы по художественным референсам. Звука и музыки пока нет. Рута перемещается статичным PNG; мельничное колесо в цельном фоне статично. Дискретные клетки воды не повторяют каждый изгиб нарисованного берега. Полный отчёт и расхождения: [docs/art-v6/report.md](docs/art-v6/report.md).

## Интерфейс v7

Плавающий HUD, постоянный деревянный лоток, бумажные окна и крупный портрет Руты в её репликах. Выбрать другую плиту можно сразу из набора; повторное нажатие снимает выбор без изменения дороги. В режиме перетаскивания листай набор вбок, а плиту тяни вверх на поле. Поворот — кнопкой вправо на 60°. Песочница, приглашение и сброс главы находятся в «Ещё…» на карте. [Реальные экраны, проверки и ограничения](docs/ui-v7/report.md).

## Пролог «Утро перед дорогой»

Новая игра начинается с шести кадров без головоломки: Рута несёт Кролику яблоки и обнаруживает пропавшую дорожку. «Дальше», «Назад» и «Пропустить» работают без таймера. После просмотра — прежний первый уровень с коротким обучением. «Посмотреть начало» доступно из меню и паузы; повтор не меняет игровую сессию и пройденные дороги.

Кадр первого просмотра сохраняется отдельно в `ruby-village:prologue:v1`. Прежняя пазл-сессия имеет приоритет при продолжении. Поворот сохраняет кадр, повтор приостанавливает движение Руты. Подтверждённый сброс главы сбрасывает и вступление. При отказе localStorage можно играть в памяти. [Отчёт, скриншоты и временные рисунки](docs/prologue/report.md).

## Сохранение

Ключ `ruby-village:chapter-1:v1`, схемаversion2. Прежние completed/introSeen и миграция version1 сохраняются: старые gate/garden/mill остаются пройденными на местах1/2/6, но мельница не пропускает новые3–5.

Дополнительные session/preferences сохраняют текущий уровень, подтверждённые плиты, размер песочницы, режим управления и уменьшение движения. Загрузка проверяет размещения; недопустимые/повреждённые клетки отбрасываются. Ранее опубликованная версия не сохраняла незавершённые раскладки. История отмены и неподтверждённый предпросмотр между перезагрузками не сохраняются. При запрете localStorage можно играть до закрытия страницы, интерфейс сообщает об ограничении.

Перезапуск очищает только текущий уровень после подтверждения. Отдельный сброс главы очищает прохождение и сессию после подтверждения. Песочница не меняет завершённые дороги.

## Проверки и данные

```sh
npm test
npm run build
# Python + Playwright + Chromium, запущенный Vite/preview:
python tests/art_browser.py http://127.0.0.1:5173/ruby-village/
python tests/chapter_browser.py http://127.0.0.1:5173/ruby-village/
python tests/prologue_browser.py http://127.0.0.1:5173/ruby-village/
python tests/ui_v7_browser.py http://127.0.0.1:5173/ruby-village/
python tests/ui_v7_review_fixes_browser.py http://127.0.0.1:5173/ruby-village/
# Воспроизведение поиска допустимых эталонов:
node --experimental-strip-types scripts/solve-art-v6.ts
```

Проверки покрывают восемь решений, воду/мост, вращение, пересечения, сохранение и миграцию. Браузер: все сцены1280×720,1920×1080,844×390,1024×768; последовательное прохождение, сессия после обновления, пауза/ориентация, песочница, мышь и сенсорное перетаскивание. Физический телефон/Safari требуют ручной проверки. Реальные скриншоты: [docs/screenshots/art-v6](docs/screenshots/art-v6).

- `src/levels.ts`, `src/art-solutions.json` — наборы и эталоны; `src/art-geometry.ts` — привязки и ручная местность; `src/chapter-art.ts` — fit.
- `src/hex.ts`, `src/game.ts`, `src/model.ts` — чистая геометрия и правила.
- `src/progress.ts`, `src/session.ts` — совместимость и сохранение.
- `src/chapter-1.story.json`, `src/story.ts` — согласованные реплики и события.
- `src/main.ts`, `src/style.css`, `src/level-art.ts` — интерфейс и отрисовка.

Исторические browser scripts для v4/v5 сохранены; их специфичные проверки относятся к соответствующим старым коммитам. Текущие точки входа art_browser/chapter_browser используют v6 проверки.
