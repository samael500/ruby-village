# Рубиновая деревня · Ruby Village

Первая глава «За калитку»: восемь спокойных головоломок для детей 6–7 лет. Рута несёт Кролику яблоки и восстанавливает исчезнувшие дороги. Без таймера, очков и наказаний. Старый прототип доступен как **Песочница**.

**Играть:** https://maks.live/ruby-village/

## Запуск

Node.js 22.18+ (CI использует 24):

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Открой напечатанный Vite адрес с `/ruby-village/`. Для телефона в одной сети используй сетевой адрес dev-сервера. Production — TypeScript + Vite + SVG, без runtime-зависимостей и сервера приложения.

## Глава и управление

Карта показывает восемь мест: двор Руты, яблоню Кролика, колодец, пекарню, ручей, мельницу, почтовый двор и лесной указатель. Участки открываются последовательно. Пройденные уровни можно повторять; книга рядом с местом позволяет перечитать диалоги. После почты доступно старое приглашение, после леса — завершение главы и анонс «Писем через лес». Уровней второй главы пока нет.

- **Выбрать и поставить:** выбери фигуру → нажми клетку → при необходимости поверни → «Поставить». Мышь показывает предпросмотр до первого клика. Клик фиксирует место, движение к кнопкам его не меняет.
- **Перетаскивать:** тяни фигуру из набора или с поля и отпусти. На телефоне цель выше пальца. Для выбранной фигуры можно использовать миниатюру «Тяни отсюда».
- Составная фигура вращается целиком на 60°. Точка обозначает опорный гекс. ⊘ и пунктирная красная обводка означают недопустимое место. Ошибка переноса и pointercancel сохраняют фигуру.
- Нажатие на уложенную фигуру выбирает весь экземпляр. «В набор» возвращает его; «Другие плиты» закрывает предпросмотр. «Отменить» возвращает последнее подтверждённое действие.
- «Проверить» ищет непрерывный путь по общей стороне гексов. Набор необязательно расходовать полностью: в почтовом дворе одна фигура лишняя.
- Обычные плиты нельзя ставить на дом, деревья, камни, клумбы и воду. У моста центральная клетка должна быть водой, обе крайние — сухими берегами. Мост делает все три клетки проходимыми.
- Настройки: режим управления, перезапуск, реплики, карта, полный экран (если поддерживается). Перезапуск уровня сохраняет завершённые дороги главы.

Вступление появляется перед первым запуском; его можно пропустить. Завершающие сюжетные реплики показываются при первой победе. Повторное прохождение даёт короткое подтверждение, но не повторяет сюжет и не выдаёт прогресс заново. У каждого места есть сохраняемое условное обозначение события победы.

Первый уровень сохраняет утверждённый двор v4, статичную Руту и материалы v5. Остальные семь мест явно обозначены как условные сцены: новые художественные фоны в сюжетный архив не входили. Там по найденному пути движется простой маркер; мельничное колесо вращается после победы. Prefers-reduced-motion отключает движение/вращение/мерцание. Чтение не нужно для управления: начало, цель, препятствия и мост обозначены на поле.

Игра работает **только в альбомной области браузера**: ширина не меньше высоты. Целевой экран — горизонтальный телефон 16:9 и компьютер. В высокой области показан экран поворота устройства с подсказкой расширить окно; управление игрой заблокировано. Возвращение автоматически сохраняет раскладку, выбранную клетку, открытый диалог и прогресс. Движение Руты приостановлено до возвращения, без перезагрузки и без требования fullscreen. Поле вписывается равномерно, без прокрутки и растяжения гексов; поворот телефона сохраняет расстановку. Кнопки не меньше 48×48 CSS px, учтены dvh и safe-area. Реплики открываются поверх поля, а не уменьшают его постоянно.

## Сохранение и миграция

Ключ localStorage остаётся `ruby-village:chapter-1:v1`; версия данных теперь 2 (`completed`, `introSeen`). Старый формат версии 1 читается автоматически: `gate` → новый уровень 1, `garden` → 2, `mill` → 6. Мельница сохраняет статус «пройдено» и доступна для повтора, но не открывает почту, пока не завершены новые уровни 3–5. Ничего из старого прохождения не сбрасывается. Изменения сцен и дорог выводятся из completed, поэтому не дублируются.

Повреждённый формат или неизвестная версия открывает новую главу. Недоступное хранилище не мешает играть в текущем запуске; карта сообщает об ограничении. Расстановка незавершённого уровня не сохраняется при обновлении или выходе на карту. «Начать главу заново» требует подтверждения и сбрасывает также отметки прочитанных вступлений.

Песочница сохраняет размеры 7×5, 9×6, 11×7 и пять прежних фигур. Смена размера очищает поле и историю, но не прогресс главы.

## Данные и решения

- `src/chapter-1.story.json`, `src/story.ts` — исходный сюжетный пакет и адаптер стабильных engine IDs. `engineReady=false` описывает статус исходного архива; реализация раскладок находится отдельно.
- `src/levels.ts` — восемь независимых раскладок и эталоны (ID фигуры, axial-опора, поворот). Первый двор 7×5 сохраняет калибровку фона; остальные уровни 11×7.
- `src/hex.ts`, `src/game.ts`, `src/model.ts` — геометрия, размещение, местность, мост и связность.
- `src/progress.ts` — миграция, сохранения и последовательное открытие.
- `src/scene-layout.ts`, `src/level-art.ts`, `src/stone-material.ts` — калибровка v4, Рута, маски гексов и стабильные материалы v5.
- `src/main.ts`, `src/style.css` — интерфейс карты, Pointer Events, диалоги, история и условные события сцен.

Эталоны всех восьми уровней проверяются тем же валидатором, что игра. В уровнях 1–6 ёмкость набора равна нижней границе длины пути (считая даже воду условно доступной): любой собственный поднабор недостаточен. Проверка победы при этом проверяет только связность. Для колодца сохранён второй допустимый обход клумбы. На почте проверена победа с одной фигурой в наборе. На ручье, мельнице и в лесу даже полностью замощённая сухая земля не соединяет берега без моста. Уникальность решений не заявляется.

## Проверки

`npm test` — содержательные проверки геометрии, размещения, местности, воды/моста, всех эталонов, нижних границ и миграции прогресса. `npm run build` — TypeScript и production-сборка.

Браузерные проверки требуют Python + Playwright и Node на PATH:

```sh
python -m venv .venv
. .venv/bin/activate
pip install playwright
playwright install chromium
# После npm run build и npm run preview:
python tests/browser_check.py http://127.0.0.1:4173/ruby-village/
python tests/chapter_browser.py http://127.0.0.1:4173/ruby-village/ /tmp/chapter-shots
python tests/art_browser.py
python tests/road_v5_browser.py
python tests/orientation_browser.py
# Дополнительно при запущенных dev (5173) и preview (4173):
python tests/art_fixture_browser.py
```

Проверяются обе схемы управления, восемь уровней, диалоги/пропуск/повторное чтение, открытие мест, перезагрузка, миграция трёх старых дорог, повтор, сброс, недоступный localStorage и изоляция песочницы. Проверены повороты составных фигур, перенос/отмена моста, запрет плит на воду, undo, reduced motion и отсутствие повторного запуска завершения. Размеры главы: 1280×720, 915×412, 740×360, 844×390. Высокие области 390×844, 768×1024 и 500×900 проверяются только как экран поворота. Скриншоты — `docs/screenshots/chapter-1-after/`.

Проверочный экран первого двора: `npm run dev`, `/ruby-village/?art-check`. Три одиночных камня уже уложены; на весь запуск отключено чтение/запись настоящего сохранения. Production игнорирует параметр.

Поддержка portrait-сцен прекращена по решению от 8 октября 2026; исторические скриншоты и ассеты не удаляются. [Альбомный режим](docs/landscape-only.md) заменяет прежние требования всех HANDOFF к портретной игре.

## Графика и ограничения

Утверждённые [v4](docs/design-v4-handoff.md) и [v5](docs/road-v5-handoff.md) сохранены. Фон первого уровня уже содержит дом, калитку и окружение; отдельные спрайты не добавлены. Пропорции Руты сохранены; наклонена только плоскость земли. [Проекция](docs/projection.md) использует сжатие 0.65 и калибровку по прежним endpoints. Для попаданий используется обратное преобразование. Шесть исходных PNG чароита обрезаются математическим гексом, без отражений; seed привязан к локальной клетке экземпляра и совпадает на поле/в наборе. Подводящие тропинки остаются убранными. Исторические ассеты и скриншоты сохранены.

[Сценарий](docs/chapter-1/CHAPTER.md), [HANDOFF](docs/chapter-1/HANDOFF.md), [отчёт реализации](docs/chapter-1/report.md). Художественные события сейчас обозначены небольшими SVG-эскизами и подписями: нарисованная калитка в растровом фоне пока не открывается. Позже нужны семь фонов, согласованные портреты жителей, состояния событий и анимация Руты. Домовой в главе не появляется.

Эмуляция не заменяет физический телефон и Safari. Сохранение локально этому браузеру и не переносится между устройствами.
