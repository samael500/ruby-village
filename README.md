# Рубиновая деревня · Ruby Village

Первый браузерный прототип: проверяем размер гексагонального поля и управление мышью и пальцами. Основной игрок — ребёнок 6–7 лет. Это свободная площадка, а не сбалансированный уровень.

**Играть:** https://maks.live/ruby-village/

## Запуск

Нужен Node.js 22.18+ (в CI используется Node.js 24).

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Открой адрес с `/ruby-village/`, который напечатает Vite. Для проверки с телефона в одной сети используй сетевой адрес dev-сервера. В production нет сервера приложения: только статические файлы.

## Управление

- **Выбрать и поставить:** выбери фигуру, нажми клетку, при необходимости поверни и нажми «Поставить». До первого клика мышь показывает предпросмотр при наведении. Клик фиксирует место: движение к кнопкам больше не сдвигает фигуру. Чтобы изменить место, нажми другую клетку.
- **Перетаскивать:** потяни фигуру из набора или с поля и отпусти. На сенсорном экране опорная клетка находится выше пальца. Для поворота выбери фигуру и используй кнопки; готовое положение можно подтвердить кнопкой «Поставить».
- Светлая точка отмечает опорный гекс. Вся фигура вращается вокруг него на 60°.
- Недопустимое место выделяется пунктирной красной обводкой и знаком ⊘. Неудачный перенос и прерывание касания сохраняют исходное положение.
- Нажатие на уложенную фигуру выбирает весь экземпляр. «Вернуть в набор» убирает его с поля.
- «Отменить действие» возвращает предыдущее подтверждённое размещение, перенос, возврат или очистку. Неподтверждённый предпросмотр можно сбросить клавишей Escape.
- Изменение размера поля возвращает все пять фигур в набор и сбрасывает историю. Изменение размера окна, режима управления или ориентации сохраняет уложенные фигуры.
- «Проверить дорогу» ищет путь через замощённые клетки и две отмеченные конечные клетки. Все фигуры использовать необязательно. Найденный путь получает светлую обводку и точки.

Предпочтительна горизонтальная ориентация. Полный экран доступен, если его поддерживает браузер. Внизу поля показаны ширина и высота гекса в CSS-пикселях.

## Устройство

TypeScript + Vite, SVG, без runtime-зависимостей и серверной части.

- `src/hex.ts` — axial/cube-геометрия, вращение, соседство, координаты и поиск пути.
- `src/game.ts` — пять отдельных экземпляров, явные формы относительно опоры, проверки размещения.
- `src/main.ts` — Pointer Events, предпросмотр, история, отрисовка.
- `src/style.css` — фиксированный экран, `dvh`, safe-area и элементы управления от 48 px.

Плиты покрывают гексы целиком: дорожных входов, выходов и внутренних соединительных линий нет. Состояние хранится в памяти страницы; перезагрузка начинает новую игру.

## Проверки

`npm test`: 14 тестов на шесть вращений, обратный поворот, уникальность и количество клеток, границы, пересечения, редактирование собственных клеток, шесть соседей, разрывы дороги и преобразование координат.

Дополнительная браузерная проверка требует Python + Playwright:

```sh
python -m venv .venv
. .venv/bin/activate
pip install playwright
playwright install chromium
# В отдельном терминале: npm run dev
python tests/browser_check.py
# Или проверить опубликованную сборку:
python tests/browser_check.py https://maks.live/ruby-village/
```

Сценарий проверяет оба режима, повороты, возврат, отмену, очистку, недопустимый перенос, pointercancel, поиск дороги, смену размера и ориентации. Проверяет все три размера поля на экранах 1280×720, 915×412, 740×360; кнопки ≥48 px, отсутствие прокрутки и обрезания поля. Использует браузерные touch-события для проверки смещения и отмены касания. Скриншоты сохраняются в `/tmp/ruby-village-*.png`.

Эмуляция не заменяет реальный телефон. На 740×360 у поля 9×6 гекс около 26×30 px, у 11×7 — 23×26 px: точность попадания ребёнком нужно проверить руками. Проверки на физических устройствах и в Safari пока не проводились. Нет сохранения после перезагрузки, карты мира, сюжета или балансировки уровня.

## Публикация

`.github/workflows/pages.yml` запускает тесты и сборку; push в `main` публикует `dist` через GitHub Actions / GitHub Pages. Pull request проходит проверки без публикации. В Settings → Pages выбран источник GitHub Actions, HTTPS включён. Домен `maks.live` унаследован от GitHub Pages аккаунта; адрес `https://samael500.github.io/ruby-village/` перенаправляет на него. Базовый путь Vite — `/ruby-village/`.

Настройка публикации соответствует [инструкции Vite для GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).
