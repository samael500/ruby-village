# Replacement whole-frame motion contract

Latest user requirement supersedes old cutout/mesh acceptance claims. Existing controller checks remain useful; old painted mesh pixels are not approved walking. Final files are complete continuous painted character frames. Pose guides/Blender rig are allowed authoring inputs, not substitutes for accepted appearance.

- Keep the approved Ruta, costume and one bag strap. Same uniform source scale, canonical root/footAnchor and declared visible nativeHeight across directions. Natural small bob is allowed; do not rescale each frame to conceal identity/height changes.
- Preserve PaintedSet/clip/sourceRect/frameSize API. Source stride is measured in painted pixels, then converted by sceneHeight136/nativeHeight to native scene coordinates. projectedStridePixels is that calibrated full-cycle scene displacement, not a guessed guide distance.
- cycleDurationMs controls sprite timing AND physical route timing. Active old800ms remains unchanged. New target about720ms is provisional: final measured stride and cadence must produce a modest increase in actual speed, calm low swing, no sliding. No route-only multiplier. Walk durations must sum to this cycle; start/stop occupy half a cycle.100 controller tests include a retimed720ms fixture; that fixture is not new artwork.
- Start moves a quarter of the calibrated full stride with acceleration; stop moves a quarter with deceleration. Walk emits contacts at phase0 andhalf-cycle. One shared phase continues through direction changes. New whole source pixels must support this, or explicitly require source retargeting.
- Minimal efficient artwork: full walk poses plus idle and whole short-step start poses for both feet. A whole start-left sequence reversed can serve stop-left: planted front foot remains fixed as the rear foot closes. Analogous right-foot source is needed for stop-right. Reuse complete frames where physically valid; never disguise part stretching as new whole poses.
- Six headings are required. Existing cameraVariants/sceneCameraVariant include the tilted well/bakery/post ground calibration; validate the actual angles/footplant before claiming those views. Do not mirror face/bag or tilt the complete body to fake another camera.
- Keep original full PNGs/prompts/guides/rejects; packed runtime atlases may use WebP with exact alpha. Final manifest owns source/delivery hashes, clip timings, semantic contacts and measured stride per view. Authors own separate source view folders; coordinator owns runtime/common integration.

Acceptance order: close-up strip and actual loop → anatomy/identity/alternation/low swing and measured support-foot trajectory → short/long native route and bridge in actual game → direction/camera turns and stable height → independent all-chapter review. A static sprite translated along a route, an atlas alone, a coarse four-key experiment or capsule prototype does not pass.
