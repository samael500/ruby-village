# Последнее решение: временная ходьба, завершение игровой главы

Максим: «сделай хоть какую анимацию походки — это мы исправим потом».
Художественная доводка походки отложена; для текущего кандидата выбран существующий
`characters-walk-v1/animated-v3` с шестью направлениями. Старые дефекты коленей
фиксируются как временное ограничение, без объявления финальной графикой.
Новые модели, волосы, native Finish и замена контроллера не блокируют этот кандидат.
Обязательны реальная смена кадров в игре, маршрут, повороты, остановка и итоговая
проверка главы, сохранений, управления и звука на production build.
Семейный тест и физический телефон не заменяются эмуляцией. Слияние и публикация
по-прежнему требуют отдельного разрешения. Уточнение заменяет противоречащие ему
ранние требования ниже только в части качества временной ходьбы.
