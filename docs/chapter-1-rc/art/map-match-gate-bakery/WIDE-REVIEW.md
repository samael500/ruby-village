# Gate/bakery wide candidate review

Core backgrounds remain byte-for-byte original candidates from fce4e7a, with lossless public copies. Playable full polygons/cameras/anchors remain unchanged.

Recommended wide candidates are opaque WebP3272×1200, originalRect {x:800,y:129,width:1672,height:941}, joinBand48. Runtime owner must apply the agreed decorative48-native-pixel opacity perimeter mask to the separate exact core and existing foreground layers. Readonly review.html demonstrates this using actual paintedBackdrop/paintedForeground and fitScene, accepted Ruta and open/closed gate. It is an asset bench, not full game QA.

Raw builtin imagegen sources are preserved. Outputs were approximately2007×784, normalized to4096×1600 then cropped[412,200,3684,1400]; do not claim native4K detail. Gate uses generated-wide-01; bakery uses corrected generated-wide-02. Core is never pasted/repainted into the delivery background.

Rejects: bakery first wide introduced unwanted sky/river; reuse-v8 produced duplicated old roof and awning (actual reject screenshot preserved); outside color correction produced streaks (source algorithm and JPEG preserved). The chosen generated surroundings remove these duplicate architecture defects.

Known candidate limitation: gate bottom foreground/core perimeter contains a small dark join at the edge in ultra-wide review. This needs integration review; do not mark this source as accepted/final without that inspection. Full game, physical phone and family checks are not run.

Evidence: twelve actual Chromium screenshots across1440×900,1280×720,1920×1080,2560×1080,844×390,740×360; full-polygon overlays and real gate-open foreground. Geometric opaque coverage is recorded in browser-six-viewports.json; this does not itself certify artistic seams.
