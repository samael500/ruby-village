# Разрыв между native-пилотом и принятой внешностью Руты

Срез: native front-proof `ac1aa06`, кадры00/23 из frozen volume09ac; канонический `public/assets/characters-v1/ruta-idle-pilot.png`; исходный accepted-style painted sprites-v2/full48, клетки00/23. Это сравнение внешности и рисунка, НЕ подтверждение принятия native-пилота и НЕ повторная оценка походки. Художественная приёмка, видимость лица в игровом E и независимая temporalQA остаются отдельными.

`appearance-side-by-side.jpg`: канон / native00 / native23 / painted-v2-00 / painted-v2-23. Механически выбран ОДИН масштаб на группу целых изображений: canonical0.45, native1.0, painted2.4, одинаковый для00/23. Никакого bbox/bodyfit, изменения PNG, совмещения суставов, зеркалирования или перекадрового масштаба. Painted клетки читаются по уже зафиксированной решётке(0,30),162×200. Дополнительный `upper-body-common-view-crop.jpg` — один общий прямоугольник итогового сравнения. Все sourceSHA/rects/viewscales в JSON; `make-comparison.py` воспроизводит артефакты.

**Ограничение ракурсов:** native — фронт yaw0 и игровая верхняя камера, канон — статичный¾, painted — иллюстрационный профиль. Взгляд вниз/укорочение ног частично вызваны этим; нельзя объявлять различие анатомических размеров доказанным по одним этим картинкам. Не предлагается менять камеру/heading, чтобы скрыть отличие. Текстурная мягкость lowres painted не считается эталонной требуемой размытостью.

| Наблюдаемое отличие | Минимальный native3D/material путь, без генерации лица |
|---|---|
| **Выражение и форма глаз.** В обоих native кадрах сильно открыты белки круглых глаз, внутренние концы бровей приподняты, маленькая закрытая улыбка даёт настороженность. Канон — уверенная широкая улыбка, выразительное верхнее веко/ресницы и спокойнее брови; painted профиль сохраняет ясный глаз и живое лицо. Это видно даже с оговоркой о камере. | Один фиксированный REST/shape-key facial study: слегка опустить внутренние брови, оформить верхнее веко и наружный угол, поднять уголки рта/щёки; оценить отдельный маленький видимый просвет улыбки. Не просто увеличивать глаза: они уже заметно велики/открыты. Согласованно перемещать head-attached глаз/веки/брови, защитить neck seam; bones/Walk не менять. Сначала front/¾ статические проверки, затем цикл. |
| **Крона и течение волос.** Native имеет широкую поперечную «крышу», почти две отдельные вертикальные боковые массы и узкие параллельные полосы. Канон/painted дают боковой пробор, крупные непрерывные S-волны, отделённые мягкими тенями. Закрытый volume устраняет alpha-cards, но сам по себе не рисует такую крону. | Авторская правка ТОЛЬКО hair REST surface: боковой пробор, несколько широких направленных волн/переходов crown→длинные пряди, увести отдельные массы от щёк. Существующий alpha-derived volume можно использовать как основу, но не закрывать ещё одним гладким колпаком. Head/body/attachment/источники движения сохраняются. Это главный геометрический разрыв; material-only его не решит. |
| **Свет/цвет/линия волос и кожи.** Native волосы читаются ярче и ровнее оранжевыми с плотными линейными бликами, лицо — гладким округлым diffuse. Канон — медно-каштановые крупные цветовые плоскости с экономными линиями и тёплой тенью. Независимый аудит6afe4ee не нашёл gamma/baked-light ошибки: нельзя лечить это ложным color-space исправлением. | После формы — одна матовая palette/ramp-study с ограниченными широкими highlight/shadow зонами и умеренной тёплой тенью; fixedRGB сохранить как источник. Не вводить glints/hashed noise. Для кожи — существующий native material с мягкой ограниченной тональной градацией, локально веки/губы/брови геометрией/родными материалами. Не наклеивать сгенерированное лицо и не перенормировать кадры. |
| **Кожаные аксессуары.** Native сапоги/сумка оранжевее и заметно пятнисто-зернистые, чем средне-коричневая ясная кожа канона/painted; на каноне подошва/клапан/латунь читаются крупными формами. | Уже имеющийся отдельный material-pilot5353033 (75%texture+25%mediumbrown) даёт лишь умеренный сдвиг и не убирает зерно; НЕ считать принятым. Следующий ограниченный шаг — согласовать один mediumbrown material contrast с крупными швами/латунными деталями, сохранить paddedUV. Сначала два статических сравнения, без master-light/gamma обходов. |
| **Графика одежды.** В native маленький красный бант и частые кольцевые складки брюк отвлекают от крупных форм жилета/воротника; канон/painted дают заметный красный узел/хвосты, широкие складки, карманы и белые манжеты. Часть деталей перекрыта позой/волосами, отсутствие всех карманов по этим видам не доказано. | Не переделывать принятый gait/скелет. Уточнить отдельные skinned garment rest meshes: читаемый воротник/узел, крупные cargo/манжеты и убрать повторяющуюся мелкую рябь складок; затем native fixed UV/material с широкими плоскостями вместо процедурного зерна. Проверить сохранение весов/швов и диапазон движения, не менять правила анимации ради вида. |

Приоритет для одного следующего художественного пилота: **выражение лица + крона/пробор**, затем palette/accessory refinement. Это предложения для native-авторинга, а не обещание, что несколько числовых регуляторов автоматически воспроизведут принятую иллюстрацию. Сходство ещё нужно предъявить в конкретном результате; наличие закрытого mesh или48PNG художественным PASS не является.

В этой работе нет рендера, правки моделей/материалов/runtime/source. Только read-only просмотр и механические review-композиты.
