# Internal studio feedback: deterministic style v7

This is an internal model/render experiment, not final graphics, user art review or numerical acceptance. Inspected updated front00/three-quarter00 (23:41:30/33), bound by hashes in `native-style-v7-viewed.json`. The superseded exposed-stock-face error is fixed and is not included as a style finding. No source edits.

Three dominant differences from accepted Ruta:

1. Hair reads as one helmet volume with a dense wavy woodgrain stripe pattern and a separate thick fringe slab. Accepted hair uses layered flowing locks with broader painted highlights and a lively long-wave silhouette. Silhouette/volume and local strand grouping need work before adding more high-frequency texture.
2. Face reads like a round doll decal: two very glossy eyes dominate, brows/lids/nose have weak structural readability, and the fixed18° head tilt produces a persistently upward-looking impression. Three-quarter cheek/eye placement does not yet create the accepted lively, expressive face. Check face registration and curved volume together; a better texture alone does not certify likeness.
3. Clothing outline still differs: green shoulder caps look like short sleeves/cape rather than a sleeveless vest over a cream rolled blouse. Trousers taper into smooth narrow boot tubes, losing baggy cargo volume, cream cuffs and substantial round ankle-boot soles from accepted idle. These silhouette features matter before adding tiny buckles/laces.

One shared UV face texture and true mesh/curve parts are deterministic inputs, which is useful for temporal consistency; their existence does not establish visual likeness. No claim about final proportions, live motion, all-view stability or user acceptance follows from these two stills.
