# Native MPFB start/stop technical prototype

This is a motion study using the explicitly rejected generic appearance. It is not final Ruta art, game activation, or user acceptance. The accepted technical carrying cycle is source commit `5ca361b`; original MPFB 2.0.18 / MakeHuman provenance and licenses remain in the parent motion documentation. Source appearance, pilot blend and runtime files are read only.

The isolated phase API is `scripts/mpfb-motion-phase-api.py`. The packed source `art/characters-mpfb-v1/motion/transitions/mpfb-start-stop-technical.blend` stores three-object action bundles (body rig, native thumb IK target, anatomical thumb pole), with the original walking bundles retained. Activate every action in a bundle together. All new poses use the actual native skinning, leg IK, original bag and one existing strap. No image mirroring, generated raster poses or per-view size corrections.

Start takes 360 ms and advances 0.2 stride: weight moves toward the support foot while the first lead step completes half a stride. Walking keeps the source 720 ms / 0.5687545573 m stride. Stop requests queue to the next heel strike (phase 0 or 0.5, at most 360 ms waiting); the trailing foot completes its shortened swing while root speed settles over 360 ms / 0.3 stride. Both feet then remain planted during 180 ms / 4 mm pelvis settling. Both native L/R variants are authored, without mirroring a render. Heading is locked during these clips; turns are not authored here.

The continuous API describes root position and speed. Saved action samples are 30 ms apart with linear interpolation, matching the walking source; the saved curves approximate the analytic root profile. Root translation must be consumed exactly once, with pose and root sampled on the same clock. A route planner must reserve stop distance instead of freezing the current swing or sliding an already planted sprite. This contract is not wired into runtime.

The E demonstration is start 0–360 ms, walk 360–1080 ms, stop 1080–1440 ms, settle 1440–1620 ms. Its GIF replays the demonstration and therefore resets at the end; that reset is not a claimed seamless cyclic trajectory. Individual walking source remains cyclic. First E rendering and author/independent visual review gate all six-view production. Current six-view manifest entries are camera specifications read from the actual existing calibrated manifest, not rendered or accepted exports.

All cameras keep 384 square / 1.70 m orthographic scale and groundScale 0.65. The fixed anchor is the projection of the rig object origin on the ground, independent of pelvis bounce, current feet or alpha bounds. Separate measurements inspect actual evaluated full render-level boots and world skin markers; planned foot bases in the API are not evidence of actual contacts. The 251 px accepted E walking height defines the shared 136 scene-pixel scale; standing can naturally be taller without being rescaled.

Reproduce with Blender 4.5.3 LTS, `--threads 2`, and isolated `BLENDER_USER_CONFIG`, `BLENDER_USER_SCRIPTS`, `BLENDER_USER_DATAFILES` under `/tmp/ruby-mpfb-motion-config`. Build using `--python scripts/mpfb-motion-transitions.py`; set `RUBY_MPFB_RENDER=1` for the 55 actual E poses. Run `mpfb-motion-transitions-check.py`, `mpfb-motion-transitions-surfaces.py`, and Python `mpfb-motion-transitions-review.py`. Check outputs remain author measurements until independent review. Rejected appearance and earlier rejected gait checkpoints remain explicitly recorded in parent documentation and Git history.

Author pilot results: 55 actual E PNGs have 55 distinct hashes and contained alpha bounds. Fresh saved-source measurements over both 55-pose native variants give render-level boot minimum +0.34487 mm, maximum flat-stance world-skin drift 0.02015 mm and native ankle/IK target error 0.0292 mm. Both demos have zero actual hand/forearm/render-level sleeve vs bag surface triangle pairs, and zero palm/finger/thumb vs existing strap pairs. The original bag/strap geometry and visibility signatures remain unchanged. Grasp distances preserve the accepted cycle’s approximately 1–2 mm clearance; this is anatomical geometric contact evidence, not force simulation.

Author inspection of the actual strip finds completed first/last steps, a retained one-strap carrying gesture, and no frozen swing. The right-lead bundle is authored and numerically measured but not separately rendered in the first E pilot. Independent naturalness review is still required before any six-view render. The prepared six-view proof script is explicitly gated and has not run.
