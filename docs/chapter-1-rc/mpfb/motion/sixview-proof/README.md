# Two-calibration compact camera proof

Technical motion only; the generic character appearance remains explicitly rejected. Independent transition review `67450e0` authorized this compact proof, not final art, game activation, a complete direction set or arbitrary-route integration.

The source is the packed transition blend at `35cddba`, activating its retained three-object original walking bundle from `5ca361b`. Each of six directions has exactly two actually rendered walking poses, phases 0 and 0.5, in each of the two production calibration groups: base angle 0 and tilted angle 0.04494904935533156, both groundScale 0.65. `src/scene-v8.json` and the existing direction manifest are read and hashed. Scene radius/origin affect scene-grid placement; they do not justify resizing the actor per direction. Every view retains the same 1.70 m orthographic scale, 384 px square and 136/251 display conversion. The renderer rotates an actual 3D camera; no west mirroring or image warping.

The manifest records native camera orbit, actor heading in scene coordinates, actual projected forward root delta versus each metadata angle, rig ground-origin anchor, evaluated foot-bone projections and evaluated source-sole toe/heel centers. A hidden measurement clone disables subdivision solely to retain stable source vertex IDs; visible boots and the source file are unchanged. These are measured skin/bone projections, not planned IK target coordinates. Root projection is independent of pelvis bounce, silhouette bounds and active foot. No per-frame anchor correction is applied.

The review strip overlays measured anchors on actual whole-frame renders and visibly labels the rejected appearance. Render checks record full alpha bounds, fixed-scale silhouette heights and root-anchor invariance. Natural silhouette-height changes across cameras are recorded rather than normalized. The actual first/second poses support camera/projection review; they do not establish natural motion over unrendered phases.

Reproduce with Blender 4.5.3 LTS CPU `--threads 2`, isolated `/tmp/ruby-mpfb-motion-config` configuration, and `RUBY_MPFB_SIXVIEW_REVIEW_GO=1 --python scripts/mpfb-motion-sixview-proof.py`, then Python `scripts/mpfb-motion-sixview-review.py`. Source hashes, scripts, native action names and render logs accompany the proof. Inherited MPFB/MakeHuman source and license records are unchanged in the parent motion study.

The separate phase API now exports exact native root deltas, support semantics, phase joins and shared body-height calibration. Analytic easing is sampled by 30 ms linear saved action keys: small chord-velocity jumps remain, so exact C1 continuity is not claimed. Fixed starts/stops and queued heel strikes do not solve arbitrary path length. A proposed goal-cell safe-area endpoint adapter is only a candidate; logical paths/goals/solutions remain untouched. No route adapter, stride scaling, root retiming or endpoint slide is implemented.
