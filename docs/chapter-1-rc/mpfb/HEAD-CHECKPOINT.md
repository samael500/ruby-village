# Two meaningful native head iterations — source checkpoint, likeness incomplete

Actual front / three-quarter / profile orthographic Cycles renders and packed .blend files: `art/characters-mpfb-v1/head-study-{1,2}`. Review sheet: `head-studies-1-2-vs-approved.jpg`. These preserve the real19158-vertex MPFB basemesh topology, native fitted eyeballs/eyelids, standard rig and authoring shape key; no overlay eyes, billboards or source-PNG deformation.

A concrete pipeline error in earlier v2/v4 was corrected: applying nonlinear stylization separately to adult basis/child macro target layers before mixing them is not equivalent to sculpting the final child mesh. The corrected sequence is native macro/details → official TargetService.bake_targets → Basis + named authoring sculpt key on the actual mixed mesh → fit rig → fit eyes/brows/hair. This eliminates the earlier pinched cheeks and uncontrolled orbital distortions.

Study1: modest native orbital/cheek/nose/smile targets and broad whole-head sculpt; calm intact child anatomy in three views, but generic/realistic, small eyes and insufficient expressive smile. Study2: moderately larger native eye opening, shorter nose and native facial-bone smile/jaw plus fitted teeth. Integrity better than overlay eyes, but expression remains doll-like, teeth/opening unattractive, eyes not approved large warm illustrative shape. **Neither is accepted likeness or final Ruta.** Original straight hair is retained solely as head framing reference, explicitly not final hair.

Reproduce with the same isolated environment as README and scripts/mpfb-head-study.py; set RUBY_MPFB_HEAD_STUDY=1 or2. Both share orthoScale.56 and camera derived from actual postsculpt head bone, preserving registration across the three views. Exact settings in settings.json. No animation authored or exported, and no runtime changed.

## Authored continuation: studies 3 and 4, both rejected

Reproduction: `RUBY_MPFB_HEAD_STUDY=3` (or `4`) with Blender `--background --threads 2 --python scripts/mpfb-head-authored.py`. These start from the preserved baked native study1 source. Shared face/lid/eyeball displacement uses the actual native eye centers, with broad orbital support, local nasal-tip reduction and continuous mouth-corner lift. New hair consists of authored overlapping wave meshes with flattened elliptical cross sections, varying breadth and tapered ends. No source-image geometry, overlay eyes, animation or runtime assets are involved. New procedural geometry is project-authored; the original MPFB/source-assets rights records remain unchanged.

Study3 actual render uncovered a second concrete shape-key failure: Blender's new key was initialized from the current evaluated mix but retained Basis as its relative key. This repeated the pre-existing whole-head enlargement, producing swollen scalp and buried eyeballs. Its source and all three actual views are retained explicitly as rejected evidence.

Study4 makes the authored key relative to `Ruta coherent child head sculpt`, so it contributes only the new local displacement. Actual front inspection confirms the eyeballs are visible again, but the aggressive smooth orbital field still creates folded cheek/nasal transitions. Hair strands are copper, volumetric, broad and tapered, but roots/fringe do not cover the scalp and the silhouette remains coarse. The face lacks approved Ruta's full warm cheeks, expressive toothy smile and clean orbital anatomy. **Study4 is rejected too; it is not a likeness candidate or a usable animation source.**

After two actual iterations, stop parameter exploration. A hand-authored facial sculpt with topology-aware eyelid/cheek constraints and a properly modeled scalp/fringe is still required.
