## Adapter prerequisites / open limits

Keep native forward(0,−1,0), source/action/shoe scale, phase duration and stride bound together. Rotate displacement once for route heading; camera projection remains separate. Evaluate integrated linear velocity inside a sample interval and add one stride per completed cycle. At a changed cycle duration scale velocity inversely; at changed world/model scale scale distance consistently. Do not reuse this curve after body, shoe, rest/action or gait edits without resampling.

A future adapter must independently test root/artist-anchor registration, actual displayed sole contact, speed-to-route/cadence mapping, route endpoints, starts/stops/turns, cycle transition and save/replay behaviour. Reaching an arbitrary route endpoint must not silently distort the declared stride/cadence contract. Current periodic curve alone guarantees none of those behaviours. Confidence gaps and inferred minimum-z ground remain limitations even if the adapter is implemented perfectly. No no-slip or final game/visual verdict follows from this technical pass.
