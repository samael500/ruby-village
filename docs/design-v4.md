# Ruby Village — дизайн игры v4

## Канон и история

Рута — девочка6–7лет, голубые глаза, светло-каштановые волосы, кремовая рубашка, зелёный жилет, бордовый платок, коричневые брюки/ботинки, сумка с ОДНИМ ремнём. Исчезающие чароитовые дороги разобщают деревню. Рута ищет причину и восстанавливает пути.
Главный антагонист — ДОМОВОЙ, хранитель забытого сада. Его карандашный образ в character-explorations.png, нижний левый. Ушастый Шелест и энт не выбраны на эту роль. Имя «Шелест» пока рабочее, не окончательное. Хранитель зовёт камни в свой сад, чтобы вернулись гости, не осознавая последствий. Развязка — восстановить связь с садом, а не победить злодея в бою.
Ёж, бельчонок и кролик утверждены как вспомогательные персонажи. Роли ниже — предложения для дальнейшей разработки, не готовые сценарии.

| Персонаж | Роль | Повод восстановить путь |
|---|---|---|
| Ёж | Почтальон, обстоятельный | Доставить накопившиеся письма |
| Бельчонок | Знаток леса, любопытный | Добраться до лесной деревни |
| Кролик | Садовник, заботливый | Вернуть доступ к саду |
| Пекарь | Житель деревни | Привезти муку с мельницы |
| Лодочник | Хозяин переправы | Дойти до пристани |
| Сапожник | Мастер, спокойный | Вернуть тропинку к мастерской |
| Учительница | Держит школьный сад | Соединить школу и деревню |
| Медсестра | Помогает жителям | Открыть дорогу к домику помощи |

Новых человеческих героев ещё предстоит визуально согласовать. Не использовать карандашные картинки как финальные цветные игровые спрайты. Не превращать задания медсестры в угрозу жизни/гонку на время.

## Игровой цикл и структура

Карта → короткая реплика/задача → один экран головоломки → дорога восстановлена → место оживает на карте. Свободная раскладка/песочница сохраняется. Наборы независимы. Easy может использовать все плиты, позже лишние. Нет обязательного расходования всех предметов, таймеров, штрафов, звёзд или экономики.
Гексы с вершиной вверх. Одно-/многогексные плиты цельные, поворот60°, соседство по общей стороне без трубных направлений. Мосты/лестницы вводятся постепенно, текущие правила движка сохраняются.

Первая глава «За калитку», план8уровней: 1До калитки(выбор/перенос),2В обход сада(поворот),3К колодцу(обход),4К пекарне(смешанные формы),5Через ручей(мост),6К мельнице(мост+обход),7Почтовый двор(первая лишняя плитка),8За деревню(обобщение, открытие леса). Это план контента; сначала реализовать оформление текущего уровня1. Решаемость новых уровней ещё не проверена.
Следующие главы: лес и письма → солнечные холмы/лестницы → сумеречный берег → забытый сад и дорога домой.

## Художественная система

Тёплая рисованная2D сказка, вид сверху под углом, насыщенные материалы и мягкие тени, лёгкая загадочность. Периферия подробная, центр спокойный. Все элементы используют одинаковые свет, масштаб, толщину контуров. Простые плоские SVG-кусты/оградки из v3 не соответствуют стилю и убираются с первого уровня.
Зелень: светлый шалфей/тёплая олива, без сплошного контрастного шума. Земля не повторяется заметным паттерном. Природные края неоднородны, не рамка прямоугольного стадиона. Свет сверху слева. Дом уютный, без пристроек/массива огромной крыши. Для фона допускаются небольшие различия архитектуры из-за генерации; проверить соответствие утверждённому дому.
Дорога: насыщенный чароитовый фиолетовый, плоские угловатые плиты, светлые естественные волнистые прожилки. Не большие кубы, не повторяющиеся параллельные волны. У каждой игровой клетки точная геометрия; фактура растровая, маска математическая.

## Экран уровня

Кадр: UI header поверх спокойного края, сцена двора, inventory внизу. В этой версии окружение дома/калитки/ограды запечено в два отдельных фона. НЕ добавлять поверх их старые спрайты дома и калитки — появятся дубликаты. Рута отдельно, точные гексы/дорога отдельно, UI отдельно.
Фон используется по исходным пропорциям, один равномерный масштаб и один offset для всех слоёв сцены. Ни fill со сжатием по осям, ни independent cover для фона. Область игры задаётся scene-contract.json, преобразование также использует её границы и реальные игровые endpoints.
Landscape и portrait — отдельные художественные композиции одного двора. Переключение фоновой композиции не меняет логические клетки, предметы и прогресс. Если привязки начала/цели невозможно совместить одним transform точной сетки с запечёнными входами: показать расхождение и выбрать обратимое решение (локальная земляная дорожка к краю start/goal или уточнение рисунка), не деформировать гексы и не менять уровень молча.

## Читаемая сетка

Не тонкие линии поверх шумной травы. Пустые клетки: слабая заливка светло-песочного #F1E7BC opacity0.10–0.18; контур тёмный зелёно-коричневый #526343 opacity0.55–0.70, ширина1.2–1.6CSSpx; светлая кромка дополнительно0.6–0.9px opacity0.3. Это начальные значения для visual tuning. Не удваивать линии общих сторон. На телефоне контур остаётся в CSSpx, а не уменьшается до исчезновения с viewport scale. Сетка видна без hover. Размещение/ошибка различимы цветом+контуром/символом. Декор не закрывает доступные клетки.

## Интерфейс

Верх: назад/карта слева, пергаментный заголовок, помощь и настройки справа. Низ: общий неглубокий деревянный tray, без гигантских карточек, предметы реальные, selected контур, вращение доступно. «Проверить» зелёная основная, undo компактная. UI отдельный живой HTML/SVG; иллюстраций готовых кнопок в пакете нет. Использовать мягкие градиенты/фактуру, аккуратные SVG иконки, избегать плоской толстоконтурной мультяшной ограды. Текст читаемый, targets≥44CSSpx, keyboard labels/focus, safe area.
На победе короткое выделение пути и радость Руты на месте. Ходьба НЕ утверждена, старые GIF не использовать. prefers-reduced-motion.

## Карта

references/world-map-concept.png — художественное направление, не финальный игровой фон/точные координаты узлов. В будущем подготовить фон без нарисованных активных дорог; roads/nodes/progress отдельными слоями. Маршруты ведут к входам реальных мест. Разблокированные дороги становятся чароитовыми, жители оживают. Подписи/иконки и hit regions отдельные. Первый выпуск показывает деревню, лес дальше мягко скрыт. Карта не линейная полоса кружков; необязательные ответвления вводить после первой главы.

## Работа с последующими сценами

Сад: яблони/грядки/изгородь. Мельница: берега/ручей/водяное колесо. Лес: тропа/почтовый домик/корни. Сумерки: ивы/фонари/светлячки, остаётся доброжелательно. Каждый фон проходит проверку свободной зоны точной сетки, endpoints, масштаба и обеих ориентаций до внедрения.
