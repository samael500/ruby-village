# Рисованные миниатюры — #48 / #79

`src/ui-miniatures.ts` использует восемь отдельных композиций из принятой иллюстрации `public/assets/chapter-map-v2/map-base.webp`. Новый арт и внешние источники не добавлены. Координаты crop перечислены в модуле в исходном пространстве 1000×400; игровая геометрия не затрагивается.

Экспорты: `renderLevelMiniature(host, levelId)` и `renderAdventureMiniature(host, 'ending' | 'letter')`. Каждый вызов заменяет содержимое host одним декоративным SVG (aria-hidden, focusable=false). Текстовое название и доступное имя сохраняет вызывающий интерфейс. Конверт — отдельный SVG с тёплой бумагой и рубиновой печатью; приглашение не изображается главой.

`contact-sheet.png`: реальные Chromium-кадры модуля, верхний ряд44CSSpx, нижний112CSSpx, DPR2. Все восемь мест, финал и письмо. Изображение просмотрено: силуэты домиков и узнаваемые детали не обрезаны. Проверка isolated-компонента, не всей игровой сцены.

Проверки: TypeScript `tsc --noEmit` PASS;20SVG в Chromium, все20aria-hidden; pageErrors=[]; исходная карта успешно загружена. Интеграционную проверку main/style выполняет координатор.
