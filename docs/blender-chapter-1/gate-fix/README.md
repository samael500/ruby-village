# Исправление калитки

Калитка развёрнута поперёк подхода, оба столба соединены с оградой.
Правая петля открывает створку наружу на 95°. От последнего участка пути
к проёму ведёт плоская земляная площадка, включающая всю клетку goal.

[Закрытая с сеткой](closed-check.png) · [Открытая с сеткой](open-check.png) ·
[Закрытая крупно](closed-detail.png) · [Открытая крупно](open-detail.png) ·
[Машинный отчёт](report.json).

Это настоящие рендеры Blender Workbench для проверки геометрии; художественная
визуализация отложена. Основные Cycles-кандидаты также пересобраны.

`check_gate.py` проверяет реальные треугольники модели после bevel: 20 положений
створки, полные полигоны всех 61 доступных клеток, отдельно силуэты и проекции
на землю. Пересечений нет. Свободный проём 1.679 при ширине гекса 1.4.
Минимальный запас до края кадра 26.54 px. Вершина площадки в goal совпадает
с якорем движка с ошибкой 0.000029 px. Намеренный сдвиг створки назад
обнаруживает пересечения с клетками 6,6 и 7,6.

Goal — внутренняя клетка с шестью доступными соседями. Поэтому проём стоит
на внешнем периметре в 211.8 px от goal, а не выдаётся за центр goal.
Игровая разметка, препятствия и решение не менялись. Вся ограда и окружение
дополнительно проверены лучами по площади 61 клетки в обоих состояниях.
Порог дома остаётся отдельной незавершённой привязкой.

```sh
blender --background --threads 8 art/blender/gate-pilot.blend --python-exit-code 1 --python scripts/blender/check_gate.py -- --render
```
