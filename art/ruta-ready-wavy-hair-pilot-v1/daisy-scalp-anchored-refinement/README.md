## Measurements before interpreting the cause

The actual original Daisy fit used X.23/depth.18/vertical.12, and source normal strength.9. It did not use vertical.14 or normal2 (those values concern a different/earlier asset). Original raw fitted hair REST Z spans.927672–1.620000m. Actual Walk0 used-geometry projection spans approximately Y127.01–350.19px; this includes alpha-invisible triangles, not a visible-hair segmentation. OBJ source/cap/ear bands and actual posed projection are retained in `source-measurements.json`.

The anisotropic ratio alone does not prove the cause of the short-looking silhouette: source asset geometry, native head pose, camera and UV alpha all contribute. A controlled lower-length intervention is therefore recorded rather than presenting the coordinator's hypothesis as established fact.

## One fixed geometry operation

Protect original REST Z≥1.40 exactly (2257 vertices). The source has no separately labelled semantic scalp/root vertex group; this is an explicit protected cap-region, not a claim of anatomical scalp-root certification. Original UV/topology/Head weights remain exact.

Below REST Z1.32, extend longitudinally by deltaZ = −.40*max(1.32−Z,0)*smoothstep(max(1.32−Z,0)/.10). This moves the lowest geometry from.927672 to.770741m, maximum extension.156931m; it does not uniformly scale or lower the entire hairstyle. Upper/crown volume remains fixed.

A smooth local band below the protected region moves forward sidelong surfaces up to.04m laterally outward and.04m backward, fading to zero byZ1.40, to reduce eye/cheek overlap. This is real REST3D deformation of the native asset, not per-frame fitting or image warping. No source face, body, bones, gait, footRoot, camera, actor scale or heading changes.
