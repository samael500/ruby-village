# One native six-lock kitbash — art review candidate

Source: Blender Studio Ellie, https://studio.blender.org/characters/ellie/v1/ , CC BY 4.0. Full attribution and unchanged original are retained in the parent asset directory. Modifications: extract existing disconnected native hair islands; one immutable 3D similarity transform per whole part; copper native hair material; rigid Head weighting and native subdivision. No mirrored geometry, new strands, sculpt, image manipulation or per-frame fitting.

The 21 original scalp/fringe islands and all six original long pony islands retain the complete original total of 7364 base vertices. Source UVs/topology survive extraction; exact per-part matrices, source attachment-proxy definitions and hashes are in manifest.json. The six long locks are distributed to the back/sides, without a scrunchie. Root proxies are terminal hair vertex means, explicitly not anatomical landmarks.

Actual front and three-quarter renders use unchanged neutral cameras, body B and native blue-eye face. No action curves are edited by this operation. These are source proofs, not runtime sprites.

Visual limitation: the front view reads as distinct thin tapered locks rather than dense flowing canonical Ruta waves. This one kitbash is **not accepted Ruta hair/likeness**, and no hidden collision/no-slip claim is made. Wardrobe/shoulder intersection in animated motion remains unverified. Existing rejected Cortu hair and temporary short haircut are hidden, preserved in source. All new names begin with ASCII `Ellie ready `; downstream styling must preserve their native shader/UV/normals and honor hide_render.
