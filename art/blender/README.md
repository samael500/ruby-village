# Исходник пилота двора

`gate-pilot.blend` — сжатый Blender 4.5.3 LTS, собственная геометрия и процедурные
материалы, внешних текстур нет. Не LFS pointer. Кандидат, не принятая графика.

Сборка и пакетный экспорт описаны в [документации пилота](../../docs/blender-chapter-1/README.md).
Проверочная коллекция `verification` выключена в чистой сцене; `gate_open` и
`gate_closed` — отдельные состояния одной створки.

`gate-geometry.blend` — отдельная основа геометрии: 77 клеточных призм, 16 пятен
препятствий, start/goal. Старые декоративные коллекции сохранены скрытыми для
сравнения. Призмы задают точную 2D-площадь; они не заменяют будущие модели дома
и калитки. [Команды и проверка](../../docs/blender-chapter-1/geometry/README.md).
